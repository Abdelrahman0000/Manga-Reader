# مانجا — موقع قراءة المانجا بالعربية

موقع لعرض وقراءة المانجا المترجمة للعربية، مبني بـ React + Vite.

## المميزات

- **الرئيسية**: قائمة المانجا الشائعة (افتراضي) مع تبويب للأحدث إضافةً.
- **قائمتي**: احفظ المانجا التي تنوي قراءتها.
- **صفحة المانجا**: البيانات والفصول مرقمة، زر إضافة للمفضلة (قائمتي)، علامات قراءة لكل فصل، وتنزيل الفصول غير المقروءة (5 / 10 / 25 / الكل) كملف مضغوط.
- **مقروء**: انقل المانجا التي انتهيت منها إلى صفحة منفصلة.
- **بحث** يعمل في كل الصفحات (بحث مباشر في المصدر، وتصفية محلية في قوائمك).
- **قارئ** يعرض صفحات الفصل كاملة مع تنقل بين الفصول.
- القوائم وعلامات القراءة محفوظة محليًا في متصفحك.

## المصدر

البيانات والصور عبر واجهة [MangaDex](https://mangadex.org) الرسمية المجانية. تغطية الترجمة العربية غير كاملة لكل العناوين — الموقع يعرض فقط العناوين التي لها فصول عربية متاحة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```
